## 1. 이 기능으로 할 수 있는 일
메인 페이지에서 큰 분류(패션의류, 식품 등)를 눌러 그 분류의 상품 목록으로 바로 가고,
화면 가장자리의 바로가기로 장바구니·고객센터에 가거나 페이지 맨 위로 돌아올 수 있다.
상품 카드의 하트로 상품 화면에 들어가지 않고 바로 찜할 수 있다.

## 2. 시작하기 전에
- 준비할 것 없음. 둘러보기는 로그인하지 않아도 된다. 찜하려면 로그인이 필요하다.

## 3. 따라 하기
### 3-1. 분류로 상품 찾기
1. 배너 아래에 한 줄로 놓인 분류 칸(예: 「식품」)을 누른다 → 그 분류의 상품만 모인 목록 화면으로 이동한다.

### 3-2. 바로가기 쓰기
1. 화면 오른쪽 가장자리(휴대폰에서는 화면 맨 아래)의 「장바구니」를 누른다 → 장바구니 화면으로 이동한다.
   (창이 좁은 PC·태블릿에서는 이 바로가기가 보이지 않는다 — 7번 참고)
2. 「고객센터」를 누른다 → 자주 묻는 질문 화면으로 이동한다.
3. 오른쪽 아래의 위쪽 화살표 버튼을 누른다 → 페이지 맨 위로 올라간다.

### 3-3. 상품 찜하기
1. 로그인한 상태에서 상품 카드 오른쪽 위의 하트를 누른다 → 하트가 파랗게 채워진다. 상품 화면으로 넘어가지 않는다.
2. 채워진 하트를 다시 누른다 → 하트가 비워지고 찜이 풀린다.
3. 찜한 상품은 마이페이지의 찜 목록에서 본다.

## 7. 알아 둘 제한 사항
- 분류 칸에는 가장 큰 분류만 나온다 — 세부 분류는 화면 위쪽 「카테고리」 메뉴에서 고른다.
- 창 가로 폭이 약 770~1340px 이면(태블릿, 창을 줄인 PC) 「장바구니」·「고객센터」 바로가기가 보이지 않고 위쪽 화살표 버튼만 보인다 — 상품을 가리지 않기 위해서다. 장바구니는 화면 위쪽의 장바구니 아이콘으로, 고객센터는 화면 맨 아래 「고객센터」로 간다.
- 바로가기에 「최근 본 상품」은 없다 — 최근 본 상품 기록은 상품 화면(product.posselect.com)에만 남아 메인 페이지에서는 읽을 수 없다. 상품 화면 위쪽의 「최근 본 상품」을 쓴다.
- 로그인하지 않고 하트를 누르면 로그인 화면으로 이동한다 — 찜은 계정에 저장되기 때문이다. 로그인하면 메인 페이지로 돌아오며, 하트는 다시 눌러야 한다.
- 하트가 채워졌다가 곧 다시 비워지면 찜이 저장되지 않은 것이다 — 잠시 뒤 다시 누른다.
